# Omnivex

Одностраничный сайт Omnivex VPN — проект Codavrix.

## Структура

- `index.html` — семантическая разметка и контент.
- `style.css` — визуальная система, стеклянная навигация, адаптивные состояния.
- `script.js` — мобильное меню и динамический год в футере.

## Запуск

Откройте `index.html` в браузере или включите GitHub Pages для ветки `main` и корневой папки.
